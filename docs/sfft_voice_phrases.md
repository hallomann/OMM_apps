# Эталонные фразы для проверки голосового ввода (СФФТ)

Произносите **только значение** на каждом шаге, после подсказки системы.

| Шаг | Поле | Пример фразы |
|-----|------|--------------|
| 1 | ПХ | «есть» / «нет» |
| 2 | КТР1 | «пятьдесят два» |
| 3 | КТР2 | «сорок восемь» |
| 4 | ПИ | «да» |
| 5 | ТВП | «нет» |

## Ожидаемый результат для набора выше

После авторасчёта проверьте классификацию на странице (плашка + при СФФТ — текст консультации НИИ ОМС).

Если система услышала только круглое десятковое число, например «сорок», она попросит повторить значение полностью. В таком случае произнесите число обычной речью: «сорок пять» или «сорок восемь».
